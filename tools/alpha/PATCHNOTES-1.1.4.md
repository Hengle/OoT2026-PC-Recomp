**IMPORTANT — Ocarina Reborn v1.1.4: PLEASE READ THE PATCH NOTES**

**Ocarina Reborn v1.1.4 — Classic UI & Launcher Improvements**

**🎨 Classic UI (optional)**
- Open **Launcher → Mods → Choose Classic UI**.
- Choose **Switch, Xbox or PlayStation button icons**, including swapped-button variants.
- Pick one of **four HUD styles** and **three title-screen logos**.
- Click **Install and enable**. Only your selected version is downloaded — about **80 MB**.
- Turn it **on or off** whenever you want. After installation, switching it on/off also works offline. Changes apply at the next game start.
- Classic UI is made by **kuledawg**. Files download directly from [GameBanana](https://gamebanana.com/mods/737280). Other HUD mods may conflict.

**🛠️ Launcher & fixes**
- After a game build or update, **Open launcher** returns you to the launcher instead of immediately starting the game.
- The installer's final option now clearly says **Launch Ocarina Reborn Launcher**.
- Added protection against running the game or shader preparation twice in the same game folder, which can cause cache conflicts.
- Improved debug reports: failed starts no longer show performance results from an older session, and cache conflicts are identified more clearly.

**ℹ️ Updating**
- Restart the launcher, click **Update**, and install over your existing version. Let the launcher update the game components if prompted.
- **No complete reinstall or game-file reimport is needed. Your saves and settings stay.**
- Classic UI itself does not require rebuilding the game. Its installation and controls have been tested; in-game visual testing is still ongoing.

**📊 Help us improve**
- If you notice stutters, press **Ctrl+F8** when they happen, then close the game and create a fresh **Debug Package**. After a crash, reopen the launcher to create it.
- Send it in **#post-your-logs-here** with the area and what happened. Reports from lower-end PCs are especially helpful.

Thanks for testing! 💙
